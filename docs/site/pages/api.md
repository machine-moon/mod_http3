# API Reference

This reference mirrors the `mod_http3` C sources: there are no classes or
namespaces, because the module is plain C.

- **[Structs](api/index_classes.md)**: the C structs that carry
  connection, session, stream, and configuration state through the module.
- **[Source Files](api/index_files.md)**: every header and translation unit,
  broken down into its functions, types, and macros.
